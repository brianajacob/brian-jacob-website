# Brian Jacob Personal Website

## Project Overview
This is a static personal academic website for Brian A. Jacob, Walter H. Annenberg Professor of Education Policy at the Gerald R. Ford School of Public Policy, University of Michigan. The site will be hosted on GitHub Pages at brian-jacob.com.

## File Structure
- `index.html` — Homepage with bio, recent research, and media coverage
- `research.html` — Full publication list organized by category
- `teaching.html` — Teaching page with course descriptions
- `media.html` — Selected media coverage page
- `cv.pdf` — CV as downloadable PDF (to be generated from Jacob_Brian_CV2026_final.docx)
- `photo.jpg` — Profile photo (to be added)

## Tech Stack
Plain HTML and CSS static site. No frameworks, no build tools. Google Fonts loaded via CDN.

## Deployment
GitHub Pages. Repository name: brian-jacob-website. Custom domain: brian-jacob.com.

### Prompt Logging
Whenever asked to update the prompt log, append all prompts from the current session to `prompt_log.md` in the root project folder. Each entry should follow this format:
[Prompt label] — YYYY-MM-DD HH:MM
[one-sentence summary]
[full prompt text]

If `prompt_log.md` does not yet exist, create it first with a header line reading `# Prompt Log`.

### Session Logging
At the end of each session when asked, append a summary to `session_log.md` recording: date, what was accomplished, any issues encountered, and next steps. If `session_log.md` does not yet exist, create it first with a header line reading `# Session Log`.
